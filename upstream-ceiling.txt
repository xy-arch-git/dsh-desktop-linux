# 支持的上游版本上限。auto-release.yml 只构建不超过这个版本的上游发布；
# 更高的版本会被跳过并开一个 issue（不失败、不发布）。细节见那个 issue。
#
# 为什么是 0.10.0：
#   上游 v0.11.0 起把宿主从「随包独立 Node」改成 Electron-as-Node，在 Linux 上会触发
#   electron/electron#46323（Electron 的二进制动态链接全局 glib 并泄漏符号，
#   与 sharp 自带的 libvips 冲突）→ sharp 段错误。
#   实测同一段 sharp 编解码：独立 Node 26 正常；Electron 43 / 44 均 SIGSEGV。
#   v0.10.0 用随包独立 Node，所以正常。
#
# 什么时候上调：上游恢复独立 Node，或 electron#46323 被修复且上游跟进。
# 改完这个版本号，同时更新 README 的兼容性说明。

0.10.0
